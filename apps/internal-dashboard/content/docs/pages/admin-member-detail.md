パス: `/members/{id}`。[管理操作の枠](/pages/admin-layout#管理操作の枠) に入り、[利用者の一覧](/pages/admin-users) の行から開く。

## 構成

上から次の順に置く。

1. ユーザー名とメールアドレス
2. 状態（有料・無料・停止中・退会済み）とメール確認、2 段階認証
3. 操作（「操作できる」以上の権限のとき）
   - 利用を停止する / 解除する
4. 契約の要約（プラン、現在期間の末、解約予定）
5. 問い合わせの一覧（新しい 5 件と、すべてへのリンク）
6. 通報の一覧（新しい 5 件と、すべてへのリンク）
7. 処置の履歴（新しい順）

- 会話の中身は出さない
- 停止・解除の確認は一覧と同じく、対象のメールアドレスと操作の種類だけをダイアログに出す

## 状態ごとの表示

| 状態 | 表示 |
| --- | --- |
| 読み込み中 | 枠を保ったまま読み込み中の表示を出す |
| 存在しない id | 見つからないことと一覧へのリンクを出す |
| 権限が無い | 権限が無いことを示す |

## 遷移

- 問い合わせの行は `/inquiries/{id}` へ、通報の行は `/reports/{id}` へ移る
- 一覧へ戻るパンくずをヘッダーに置く
