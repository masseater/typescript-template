title: 利用者アプリの規約への同意

---

パス: `/agreement`。[会員の枠](/pages/member-layout#会員の枠) に入るが、最新の規約に未同意のときは他の会員ページより先に出す。

登録直後の同意は [登録の段階](/pages/member-welcome) が持つ。実体は [信頼と安全](/data-model/trust) の AgreementVersion である。

## 構成

上から次の順に置く。

1. 見出し「利用規約が更新されました」
2. 変更の要約（公開時に管理者が書いた 1〜3 文。無ければ出さない）
3. 利用規約へのリンク（公開済みの最新版）
4. 「同意して続ける」ボタン

- 同意したら、開こうとしていたページへ移る。無ければホームへ移る
- 同意するまで、会員の枠の他のページには進めない。会員の枠は開くたびに未同意の版を取り、止める種類があれば `/agreement?redirect={開こうとしたパス}` へ移す
- 会員 API も同じ判定を 1 か所の共通処理で使う。セッション・認証・登録の段階・同意の API 以外は、同意まで `428 Precondition Required` と未同意の `kind` の一覧を返す

## 状態ごとの表示

| 状態                 | 表示                 |
| -------------------- | -------------------- |
| すでに最新へ同意済み | ホームへ移る         |
| 保存に失敗した       | 理由を本体の下に出す |

## 遷移

- 「同意して続ける」で、redirect または `/home` へ移る
- 公開の利用規約ページ（`/terms`）とプライバシーポリシー（`/privacy`）は誰でも開けるが、同意の記録は残さない
- 同意の履歴は [設定](/pages/member-settings#規約への同意) の `/settings/agreements` に、種類・版・同意した日で並べる
