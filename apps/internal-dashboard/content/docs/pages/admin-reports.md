パスは 2 つある。どちらも [管理操作の枠](/pages/admin-layout#管理操作の枠) に入る。

- `/reports`: サイドバー「通報」から開く一覧
- `/reports/{id}`: 一覧・利用者の詳細から開く 1 件

実体は [信頼と安全](/data-model/trust) の Report と ModerationAction が持つ。

## 一覧

上から次の順に置く。

1. 見出し「通報」
2. 状態の絞り込み（未対応・処置済み・却下）
3. 件数と表
4. ページ送り

| 対象 | 理由     | 状態   | 通報者 | 受付日   |     |
| ---- | -------- | ------ | ------ | -------- | --- |
| 佐藤 | 迷惑行為 | 未対応 | 山田   | 2026/9/1 |     |

- 対応待ちの件数をサイドバーのバッジに出す
- 行を選ぶと詳細へ移る

## 詳細

上から次の順に置く。

1. 対象のユーザー名（`/members/{id}` へのリンク）
2. 理由と本文
3. 通報者（会員ならリンク）
4. 状態
5. 「操作できる」以上のときの操作
   - 対象を停止する
   - 却下する
   - 警告を残して対応済みにする
6. この通報に紐づく処置の履歴

確認のダイアログには、対象のメールアドレスと操作の種類だけを書く。

## 状態ごとの表示

| 状態                   | 表示                                     |
| ---------------------- | ---------------------------------------- |
| 条件に一致する件が無い | 「条件に一致する通報はありません」を出す |
| 存在しない id          | 見つからないことと一覧へのリンクを出す   |
| 閲覧のみ               | 処置の操作を出さない                     |

## 遷移

- 対象と通報者から利用者の詳細へ移る
- 停止したら利用者の詳細の状態も停止中になる
