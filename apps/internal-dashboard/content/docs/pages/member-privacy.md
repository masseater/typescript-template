## 記載する内容

1. 見出し「プライバシーポリシー」
2. 本文
   - 取得する情報の種類（アカウント、プロフィール、利用状況など）
   - 利用目的（サービス提供、サポート、改善など）
   - **ページの閲覧と遷移の計測**
     - 利用者アプリでは Google Analytics を使い、どのページが開かれたか・どう遷移したかを計測する
     - 計測は staging と本番の利用者アプリだけで行い、ローカル開発と自動テストでは Google へ送らない
     - 計測 ID が未設定の環境ではスクリプトを読み込まない
     - 会員制の URL に含まれる利用者 ID は、Google に送る前に `/users/_` のように特定できない形へ置き換える。メールアドレスや利用者 ID を計測データに含めない
     - AI や bot の操作も計測から除外しない。User-Agent で区別できる
   - 第三者提供・委託（Google Analytics を含む）
   - 保管期間、開示・訂正・削除の求め方、お問い合わせ先
   - 退会した会員が送ったメッセージは相手の側に残り、差出人は「退会した会員」と表示する

## 公開

- 版の管理は [規約の版](/glossary/agreement-version) に従う。種類は `privacy`
- プライバシーポリシーの公開だけでは [規約への再同意](/pages/member-agreement) を求めない
