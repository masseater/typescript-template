パス: `/admins`。[管理操作の枠](/pages/admin-layout#管理操作の枠) に入り、「管理者を追加できる」権限の管理者だけが見る。

実体は [アカウント](/data-model/accounts) の AdminAccount と Invite が持つ。

## 構成

上から次の順に置く。

1. 見出し「管理者」
2. 「招待する」
3. 管理者の表

| 名前 | メールアドレス     | 権限       | 状態 | 登録日     |     |
| ---- | ------------------ | ---------- | ---- | ---------- | --- |
| 鈴木 | suzuki@example.com | 操作できる | 有効 | 令和 8/9/1 | ⋯   |

権限の列で権限を変える。行末の操作から、自分以外の管理者を無効にする、または無効にした管理者を有効に戻す。無効にした管理者は管理者アプリにログインできず、開いていたセッションも終わる。データは残り、有効に戻せば元どおりに使える。

利用者を管理者にする操作はない。管理者アカウントは招待か、最初の 1 人を作る DB のブートストラップでだけ生まれる。

## 招待

「招待する」で同じページ内に入力を出す。

1. メールアドレス
2. 権限（閲覧のみ / 操作できる / 管理者を追加できる）
3. 「招待メールを送る」

受け取り側は `/invite/{token}` で、招待されたメールアドレスを確認し、名前とパスワードを入れてアカウントを作る。招待の有効期限は 7 日で、1 回受け取ると同じリンクは使えない。

- 同じメールアドレスに開いている招待があるうちは、次の招待を送れない
- 会員・管理者・社内の利用者としてすでに登録されているメールアドレスには招待を送れない
- トークンはハッシュだけを保存し、リンクは招待メールにしか現れない

## 状態ごとの表示

| 状態                                             | 表示                                 |
| ------------------------------------------------ | ------------------------------------ |
| 権限が無い                                       | 権限が無いことを示す                 |
| 最後の「管理者を追加できる」を下げようとした     | 実行できず、理由を通知する           |
| 最後の「管理者を追加できる」を無効にしようとした | 実行できず、理由を通知する           |
| 招待に失敗した                                   | 入力を残したまま理由を出す           |
| 招待のリンクが切れている・使われている           | `/invite/{token}` で再送の依頼を促す |

## AI エージェント連携

管理者は `/mcp` の MCP サーバーに OAuth で AI エージェントを接続できる。連携の許可は `/consent` で行い、許可した管理者の権限の範囲だけが MCP から使える。

## 監査ログ

招待・権限の変更・無効化と有効化は、それぞれ操作した管理者と対象を [監査イベント](/glossary/audit-event) に残す。画面からの操作は `ui`、MCP からの操作は `mcp` を channel に記録する。

## 遷移

- 招待メールのリンクは認証前の枠の `/invite/{token}` へ入る
- ログインは [管理者のログイン](/pages/admin-login) が持つ
