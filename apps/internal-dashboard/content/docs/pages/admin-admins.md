パス: `/admins`。[管理操作の枠](/pages/admin-layout#管理操作の枠) に入り、「管理者を追加できる」権限の管理者だけが見る。

実体は [アカウント](/data-model/accounts) の AdminAccount と Invite が持つ。

## 構成

上から次の順に置く。

1. 見出し「管理者」
2. 「招待する」
3. 管理者の表

| 名前 | メールアドレス     | 権限       | 最終ログイン |     |
| ---- | ------------------ | ---------- | ------------ | --- |
| 鈴木 | suzuki@example.com | 操作できる | 2026/9/1     | ⋯   |

行末の操作から、権限の変更と、自分以外の管理者の無効化を選ぶ。

## 招待

「招待する」で同じページ内に入力を出す。

1. メールアドレス
2. 権限（閲覧のみ / 操作できる / 管理者を追加できる）
3. 「招待メールを送る」

受け取り側は `/invite/{token}` でアカウントを作る。招待の有効期限は 7 日である。

## 状態ごとの表示

| 状態                                         | 表示                       |
| -------------------------------------------- | -------------------------- |
| 権限が無い                                   | 権限が無いことを示す       |
| 最後の「管理者を追加できる」を下げようとした | 実行できず、理由を通知する |
| 招待に失敗した                               | 入力を残したまま理由を出す |

## 遷移

- 招待メールのリンクは認証前の枠の `/invite/{token}` へ入る
- ログインは [管理者のログイン](/pages/admin-login) が持つ
