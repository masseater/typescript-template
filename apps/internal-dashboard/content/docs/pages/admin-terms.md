パスは 2 つある。どちらも [管理操作の枠](/pages/admin-layout#管理操作の枠) に入る。

- `/terms`: サイドバー「規約」から開く一覧
- `/terms/{version}`: 1 つの版の内容と公開

実体は [信頼と安全](/data-model/trust) の AgreementVersion が持つ。会員の再同意は [規約への同意](/pages/member-agreement) が持つ。

## 一覧

上から次の順に置く。

1. 見出し「規約」
2. 「新しい草稿」
3. 版の表（種類・版・状態・公開日）

状態は草稿・公開済みである。公開済みの最新の利用規約だけが、会員の再同意の対象になる。

## 版の詳細

上から次の順に置く。

1. 種類（利用規約 / プライバシーポリシー）と版
2. 本文の編集（草稿のとき）または本文の表示（公開済み）
3. 変更の要約（会員の再同意画面に出す 1〜3 文。任意）
4. 「操作できる」以上のとき、草稿なら「公開する」

公開の確認には、会員が再同意を求められるかどうかを書く。プライバシーポリシーの公開だけでは再同意を求めない。

## 状態ごとの表示

| 状態               | 表示                                           |
| ------------------ | ---------------------------------------------- |
| 版が無い           | 「まだ規約はありません」と「新しい草稿」を出す |
| 存在しない version | 見つからないことと一覧へのリンクを出す         |
| 閲覧のみ           | 編集と公開を出さない                           |

## 遷移

- 公開に成功したら一覧へ戻り、公開したことを通知する
