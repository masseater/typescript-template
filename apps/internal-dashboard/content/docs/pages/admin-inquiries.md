パスは 2 つある。どちらも [管理操作の枠](/pages/admin-layout#管理操作の枠) に入る。

- `/inquiries`: サイドバー「問い合わせ」から開く一覧
- `/inquiries/{id}`: 一覧・利用者の詳細から開く 1 件

実体は [信頼と安全](/data-model/trust) が持つ。wiki は同じ Inquiry を読むだけで、返信はここだけが書く。

## 一覧

上から次の順に置く。

1. 見出し「問い合わせ」
2. 状態の絞り込み（受付・対応中・完了）
3. 件数と表
4. ページ送り

| 件名 | 経路 | 状態 | 相手 | 最終更新 |  |
| --- | --- | --- | --- | --- | --- |
| 料金について | 会員 | 受付 | 山田 | 2026/9/1 |  |

- 経路は「公開」か「会員」
- 相手は、会員ならユーザー名、公開ならメールアドレス
- 対応待ちの件数をサイドバーのバッジに出す
- 行を選ぶと詳細へ移る

## 詳細

上から次の順に置く。

1. 件名・状態・経路
2. 相手へのリンク（会員なら `/members/{id}`、公開なら mailto）
3. メッセージの並び（古い順）
4. 「操作できる」以上のとき、返信の入力欄と「返信する」、状態を完了にする操作

## 状態ごとの表示

| 状態 | 表示 |
| --- | --- |
| 条件に一致する件が無い | 「条件に一致する問い合わせはありません」を出す |
| 存在しない id | 見つからないことと一覧へのリンクを出す |
| 閲覧のみ | 返信の入力欄を出さない |

## 遷移

- 会員の相手名から利用者の詳細へ移る
- wiki の問い合わせ画面は読むだけで、仕様の本体はこちらである
