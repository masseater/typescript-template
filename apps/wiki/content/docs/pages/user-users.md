title: 利用者アプリのユーザー一覧

パス: `/users`。[会員の枠](/pages/user-layout#会員の枠) に入る。

管理者アプリのユーザー一覧とは別のもので、利用者どうしが互いを見つけるためにある。出すのは [プロフィール](/pages/user-profile) で他の利用者に見せている項目だけで、メールアドレス・権限・認証の設定状況は出さない。

## 構成

上から次の順に置く。

1. 見出し「ユーザーを探す」
2. 名前で検索する入力欄と「検索」ボタン
3. 件数（例: 123 人中 1〜24 人）
4. 利用者のカードの並び
5. ページ送り（例: ‹ 1 2 3 … 10 ›）

カードには次を置き、カード全体をその利用者のプロフィールへのリンクにする。

- アバター（名前の頭文字）
- ユーザー名
- 自己紹介の先頭 2 行

- 並ぶのは、メールアドレスを確認済みの利用者である。自分も含む
- 登録日の新しい順に並べ、1 ページに 24 人を出す
- 画面幅に応じて 1〜3 列に並べる

## URL に持つ状態

検索条件とページは URL のクエリに持つ。再読み込み・戻る・URL の共有で同じ一覧を再現する。

| クエリ    | 値                          | 省略したとき |
| --------- | --------------------------- | ------------ |
| `keyword` | 名前の一部（100 文字まで）  | 絞り込まない |
| `page`    | 1 以上 1,000,000 以下の整数 | `1`          |

- 「検索」を押すか入力欄で Enter を押したときに条件を URL へ反映し、`page` を外す
- 入力欄を空にして検索すると `keyword` を外す
- 値の形が合わないクエリは URL から取り除き、省略したときと同じ一覧を出す

## 状態ごとの表示

| 状態                              | 表示                                                                         |
| --------------------------------- | ---------------------------------------------------------------------------- |
| 読み込み中                        | カードの並びの枠を保ったまま、カードの位置に読み込み中の表示を出す           |
| 条件に一致する利用者がいない      | 並びの代わりに「条件に一致するユーザーはいません」と、条件を外すリンクを出す |
| `page` が最後のページを越えている | 並びの代わりに、該当する利用者がいないことと 1 ページ目へのリンクを出す      |
| 一覧を取得できなかった            | 並びの代わりに、取得できなかったことと再試行ボタンを出す                     |

## 遷移

- カードを選ぶと `/users/{id}` へ移る
- 会員の枠に入れないときの行き先は [枠へ入る条件](/pages/user-layout#枠へ入る条件) に従う
