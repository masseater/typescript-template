パス: `/`。`vp run @repo/commander#start` で手元の `http://127.0.0.1:3090` に開く。ログインもページの切り替えも無い。

## 構成

画面を左右に分ける。幅が狭いときは上下に並べる。

1. 左: 司令塔との会話
   - 見出し「司令塔」
   - 会話の記録。自分の発言、司令塔の返答、司令塔が実行した操作の 1 行表示、通知を古い順に並べ、最新が常に見える位置に保つ
   - 入力欄と「送信」。Enter で送り、Shift+Enter で改行する
   - 司令塔が進めている間だけ「止める」を出す
2. 右: タスク
   - 見出し「タスク」
   - 「要判断」「レビュー待ち」「実行中」「待ち」「準備OK」「完了」の順に、空でないグループだけを件数付きで出す
   - 各行は題と ID。要判断と実行中の行には最新のコメントを、レビュー待ちの行には誰の確認を待っているかを、待ちの行には待っている相手の題と、担当がまだ付いていれば「停止予定」を、完了の行には完了の理由を添える
   - 行を選ぶと、一覧の下にそのタスクの詳細を出す

タスクの詳細は上から次の順に置く。

1. 題、ID と担当
2. 目的と完了の条件
3. コメントを古い順に並べたもの
4. コメントの入力欄と「ワーカーへ伝える」。Enter で送り、Shift+Enter で改行する。届くのは次のチェックポイントであることを添える

## 状態ごとの表示

| 状態 | 表示 |
| --- | --- |
| アプリにつないでいる途中 | 「つないでいます…」だけを出す |
| 対象の場所に bd のデータベースが無い | 画面全体に、その旨と場所、「ここに作る」を出す。作ると空のタスク一覧になる |
| 会話がまだ無い | 会話の位置に「頼みたいことをそのまま書いてください。」を出す |
| 司令塔が進めている | 会話の末尾に「進めています…」を出し、返答を届いた分から足していく |
| 司令塔が進めている間に送った | 会話の末尾に、前の返事のあとに送ることを添えて薄く出す。順番が来たら自分の発言として会話に入る |
| タスクに動きがあり、アプリが司令塔を起こした | 起こしたことを会話の中に通知として残し、続けて司令塔の返答を出す |
| タスクをまだ読めていない | タスクの位置に読み込み中の表示を出す |
| タスクが 1 件も無い | 「タスクはまだありません。」を出す |
| bd を読めなかった | タスクの上に、読めなかったことを出す。読めた時点で消える |
| アプリとの接続が切れた | タスクの上に、つなぎ直していることを出す。アプリを起動し直しても、再読み込みなしでつながった時点で消える |
| 送信・コメント・作成が届かなかった | その操作の下に、届かなかったことを出す。入力は消さない |
| 司令塔を実行できなかった・止めた | 会話の中に通知として残す |
| 前の会話を引き継げなかった | 新しい会話で始め直したことを、会話の中に通知として残す |
| 司令塔が許可されていない操作を試みた | その操作を止めたことを、会話の中に通知として残す |

- タスクの一覧とコメントは、再読み込みなしで 5 秒ごとに新しくなる。送信の直後、コメントの直後、司令塔の返答が終わった直後はすぐに新しくなる
- 会話の記録は対象の場所ごとに残り、アプリを起動し直しても続きから話せる
