パス: `/`。[管理操作の枠](/pages/admin-layout#管理操作の枠) に入る。

## 構成

上から次の順に置く。

1. 見出し「ユーザー一覧」
2. 検索条件を 1 行に並べる
   - 名前・メールアドレスで検索する入力欄
   - 権限の選択
   - メール確認の選択
   - 「検索」ボタン
   - 「条件をクリア」
3. 件数（例: 123 件中 1〜50 件）
4. ユーザーの表
5. ページ送り（例: ‹ 1 2 3 … 10 ›）

表の列は次のとおりで、行末の `⋯` から、その行のユーザーへの操作を選ぶ。

| 名前 | メールアドレス     | 権限         | メール確認 | 2段階認証 | 登録日    |     |
| ---- | ------------------ | ------------ | ---------- | --------- | --------- | --- |
| 山田 | yamada@example.com | 管理者       | 確認済み   | 設定済み  | 2026/9/1  | ⋯   |
| 佐藤 | sato@example.com   | 一般ユーザー | 未確認     | 未設定    | 2026/8/30 | ⋯   |

- 表は登録日の新しい順に並べ、1 ページに 50 件を出す
- 画面幅が表より狭いときは、表だけを横にスクロールさせる

## URL に持つ状態

検索条件とページは URL のクエリに持つ。再読み込み・戻る・URL の共有で同じ一覧を再現する。

| クエリ     | 値                                         | 省略したとき |
| ---------- | ------------------------------------------ | ------------ |
| `keyword`  | 名前かメールアドレスの一部（100 文字まで） | 絞り込まない |
| `role`     | `admin` / `user`                           | 絞り込まない |
| `verified` | `true` / `false`                           | 絞り込まない |
| `page`     | 2 以上の整数                               | 1 ページ目   |

- 「検索」を押すか入力欄で Enter を押したときに条件を URL へ反映し、`page` を外す
- 「条件をクリア」で `keyword`・`role`・`verified`・`page` をすべて外す
- 値の形が合わないクエリは URL から取り除き、省略したときと同じ一覧を出す

## 状態ごとの表示

| 状態 | 表示 |
| --- | --- |
| 読み込み中 | 表の枠を保ったまま、行の位置に読み込み中の表示を出す |
| 条件に一致するユーザーがいない | 表の代わりに「条件に一致するユーザーはいません」と条件をクリアを出す |
| `page` が最後のページを越えている | 表の代わりに、該当するユーザーがいないことと 1 ページ目へのリンクを出す |
| 一覧を取得できなかった | 表の代わりに、取得できなかったことと再試行ボタンを出す |

## 行の操作

| 操作 | 確認 | 成功したとき |
| --- | --- | --- |
| 管理者にする / 一般ユーザーにする | 対象のメールアドレスと変更後の権限をダイアログで示す | 対象の既存セッションが失効したことを通知し、同じ条件で一覧を取り直す |
| 削除 | 対象のメールアドレスを示し、取り消せないことをダイアログで示す | 削除したことを通知し、同じ条件で一覧を取り直す |

- 実行中は、その行の操作を押せない状態にする
- 最後の管理者を降格・削除しようとしたときは、実行できないことを通知し、一覧を変えない
- 操作中に自分の管理者権限が失われていたときは、実行できないことを通知する

## 遷移
