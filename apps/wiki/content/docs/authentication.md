## サインイン

メールアドレスとパスワードで登録し、届いた確認メールのリンクを開くと利用を始められます。

## パスキー

WebAuthn のパスキーを登録すると、パスワードを入力せずにログインできます。

## 多要素認証

認証アプリのワンタイムコードを登録できます。端末をなくしたときは、登録時に表示されたバックアップコードで入れます。

## 管理者

管理画面は一般ユーザー向けのアプリと別の Worker で動きます。管理者の操作には、多要素認証を済ませた強いセッションが必要です。

wiki も別の Worker で動き、管理者アカウントでログインした人だけが読めます。ログイン状態は管理画面と共有しないので、wiki でもあらためてログインします。

## MCP クライアントの認可

wiki の MCP サーバーは OAuth 2.1 で保護しています。MCP クライアントは動的クライアント登録で自身を登録します。そのあと、管理者が wiki にログインして連携を許可すると、アクセストークンを受け取ります。

管理者の権限を外すと、そのユーザーが発行したトークンでは MCP を使えなくなります。
