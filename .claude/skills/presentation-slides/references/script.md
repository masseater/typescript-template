# 台本

台本は発表者ノートとは別に、1 つの文書として通しで書く。話し手はこの台本で練習する。

## 冒頭

```
題:           <題>
聴衆:         <誰か、何を知っているか>
目的:         <知ってもらう / 説得する / 売る / 教える / 決めてもらう>
聞き手の問い: <問い>
持ち時間:     <分>・時間厳守: <はい / いいえ>
場:           <登壇 / 会議室 / オンライン / 勉強会>
質疑:         <途中 / 最後>
```

## 章ごと

```
### [n] <章の名前>   [目安: 00:00 – 00:00]   スライド <a–b>

主張
<この章で伝える 1 文>

話すこと
<根拠、具体例、数字を、口に出す順に。箇条書きにせず話し言葉の文で書く。>

聴衆にとっての意味
<この聴衆にとって何を意味するか>

要約（口に出す）
「<1 文>」

つなぎ
「<要約 → なぜ大事か → 次に何を話すか → 両者の関係>」

削れる: はい / いいえ
```

## 一字一句書く部分

最初の 60 秒と最後の 60 秒は一字一句書く。

- 最初の 60 秒: 挨拶、自己紹介、扱う範囲、目次を 1 行、質問の受け方。
- 最後の 60 秒: 終わりの合図、要点、聞き手への呼びかけ。

中盤は話し手が言い換えられる話し言葉の文でよい。

## 想定質問

```
| 想定質問 | 短い答え | 根拠として出すもの |
|---|---|---|
```

5 問以上用意し、会場でいちばん懐疑的な人がすでに考えている反論を 1 問必ず入れ、その答えから先に書く。手元に数字がない質問には「今は手元にありません。何日までに送ります」と、送る期日を付けて答える。

## 時間の確認

声に出して読み、各章の実際の経過時間を目安の横に書く。黙読は音読より約 3 割速いので、紙の上で収まっても音読で超えることが多い。超えたら削れる印の章を削り、早口で合わせない。
