# 仕上げの確認

- [ ] 冒頭の問いか主張を、終盤で「（再掲）」として回収している
- [ ] まとめのスライドだけを読んで、覚えて帰ってほしい 1 文が分かる
- [ ] 目次の章の名前が、覚えて帰ってほしい 1 文の語句から作られている
- [ ] 本論の各章が主張、実物、想定反論と答え、要約の 1 文を持つ
- [ ] すべてのつなぎが台本に書かれている。複数人なら交代の言葉も書かれている
- [ ] 章の数が 2〜5 個で、枚数が持ち時間の目安に収まる
- [ ] 最初の 60 秒と最後の 60 秒が一字一句書かれている
- [ ] 見出しを順に読むだけで話の筋が通る
- [ ] 題と見出しが、題材の名前と話す内容か主張だけでできている
- [ ] 全スライドが `slides.md` のスライドの種類のどれか 1 つに当てはまる
- [ ] 続けて映す図やコードは、1 枚ごとに 1 か所だけ変わっている
- [ ] 引用のすべてに話者と出典がある
- [ ] `../SKILL.md` の「スライド」の 6 項目を全スライドで満たす
- [ ] 本文の文字が最後列から読める大きさで、実際の表示サイズで確かめた
- [ ] デモがあるなら、失敗したときの録画か画面写真がある
- [ ] 付録に、反論 1 問を含む想定質問への答えが 5 問以上ある
- [ ] 削れる章に印がある
- [ ] 声に出して 1 回通し、時間を測った。測れないときは台本の字数を 1 分 300 字で割って見積もり、見積もりだと明記した
