# Performance Optimization

パフォーマンス改善は、必ず以下のループで行う。

1. 計測する。まず OpenTelemetry で対象の性能を計測できる状態にして、改善前のベースラインを取得する
2. 改善する。計測結果からボトルネックを特定し、ボトルネックに対する改善を1つずつ行う
3. 再計測する。改善前と同じ条件で計測する。実測値で改善したことを確認する。改善していなければ、次の仮説を立てて再度改善する。

「理論上速くなった」「コードを改善した」だけでは完了としない。実測で性能向上を確認するまでループを続ける。

- 推測だけでなく、計測結果にてボトルネックを決めること。
- 改善前後で比較条件を変えないこと。
- 性能改善によるregressionも確認すること。
