# ダッシュボードの設計とレビュー

`references/guidebook.txt` はガイドブックの原文をダウンロードしたままのファイルで、文字コードは Shift_JIS、改行は CRLF になっている。`iconv -f CP932 -t UTF-8 .claude/skills/digital-government-dashboard/references/guidebook.txt` で UTF-8 にして開く。見出しは `# 2.1 目的を定義する` の形になっている。作業の段階に合う節を見出しで探して開く。

1. 目的、見る人、利用場面、制約を決める: `# 2 要件の整理` から `# 2.3 要件定義ワークシート` まで。
2. 載せる情報を選び、レイアウトを組み、要望を反映する: `# 3 プロトタイピング` から `# 3.5 要望を元に改善する` まで。
3. グラフの種類、色、コントラスト比、表現の良し悪しを決める: `# 4 情報表現のポイント` から `# 4.5 Do’s Don’ts` まで。
4. 仕上げを確かめる: `# 5.4 チェックリスト` と `# 5.5 アクセシビリティの対応` の項目を 1 つずつ当てる。

設計の判断やレビューの指摘には、根拠にした節の番号を添える。
