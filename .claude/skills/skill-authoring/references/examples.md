# 具体例を書く

- 指示なしで頼むとこのリポジトリの規則に反する形が出てくる作業には、避けたい形と望む形を並べたコード例を書く。規則の文だけで済ませない。
- 2 つの形は同じ対象を書き分けたものにする。望む形はこのリポジトリに実在するファイルから取り、パスを添える。避けたい形は、その作業を指示なしで頼んだときに実際に出てきた形にする。
- 避けたい形が lint で落ちること、望む形が lint を通ることを確かめる。落とした規則の名前や件数は例に書き写さない。
- 1 つの例に、繰り返し出てくる誤りをまとめて入れる。規則 1 つごとに例を作らない。
- 例は、その作業をするときに読まれる skill や reference に置く。
- 形は `../../reviews/references/test-design.md` の「書き方の例」に合わせる。
