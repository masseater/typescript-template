---
name: config-rule-cleanup
description: 不要な設定の無効化・緩和や、特定範囲だけ既存設定を上書き・除外する変更をレビューし、既存の制約を維持するようコードや設定を修正する。
---

対象となる変更に含まれる、既存の制約を無効化・緩和する設定、および特定範囲だけ既存設定を上書き・除外する設定を確認する。

各設定について、以下を行う。

1. 既存の設定と比較し、その変更が何を無効化・緩和・除外・変更しているか確認する。
2. その変更が本当に必要か確認する。
3. 不要であれば設定を削除し、既存の設定を維持するようコードや設定を修正する。
4. 本当に必要な場合のみ設定を残し、適用範囲を可能な限り狭くする。
5. 修正後、関連するチェックを実行して確認する。

以下をレビュー対象とする。

- 設定の無効化・緩和
- 設定ファイルでの override
- 特定のファイル・ディレクトリだけを対象とした override
- 特定のファイル・ディレクトリだけを対象とした ignore / exclude
- 継承した設定の一部だけを変更する設定
- lint、formatter、type checker、test runner などのルールの変更
- CI/CD のチェック無効化や失敗の無視
- validation、coverage、strictness などの制約を弱める設定

以下は、設定変更を正当化する理由として認めない。

- 修正にコード変更が必要
- 現在正常に動作している
- 設定が不便・冗長
- 既存コードである
- リファクタリングが必要
- 修正に作業量がかかる

既存の設定を維持することが意図した実装や仕様と両立しない場合は、設定変更を残してよい。

設定変更を残す場合は、変更の対象と理由が明確であり、必要以上に広い範囲へ影響しないことを確認する。

不要な設定変更を発見した場合は、設定を削除して問題を修正し、関連するチェックが通ることを確認する。
