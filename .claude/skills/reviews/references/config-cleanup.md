# 設定の上書きと除外

変更対象の設定と、その上位・共通設定を比べる。

- `include` より `exclude` を基本にし、新しい対象の追加で意図せず検査対象から漏れる構成を避ける。
- 既存の設定を上書き・無効化・緩和・除外する設定は、無ければどの制約が壊れるかを言えるときだけ残す。説明できないものは削除し、既存の制約を維持するようコードや設定を直す。
- 適用範囲は可能な限り狭くする。共通設定で解決できるものを workspace 固有の設定で上書きしない。
- 緩和のために別の設定や例外を足して帳尻を合わせない。
- デフォルト値と同じ値を書かない。
- 直した後、関連するチェックを実行する。
