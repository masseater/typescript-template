# 仕上げの確認

- [ ] 結論のスライドだけを読んで、覚えて帰ってほしい 1 文が分かる
- [ ] 本論の各セクションが主張、根拠、聴衆にとっての意味、要約の 1 文を持つ
- [ ] すべてのつなぎが書かれている。複数人なら交代の言葉も書かれている
- [ ] セクション数が持ち時間に収まる（20 分なら 3 つ）
- [ ] 最初の 60 秒と最後の 60 秒が一字一句書かれている
- [ ] 議題とまとめのスライドがある
- [ ] タイトルを順に読むだけで話の筋が通る
- [ ] 話し手が読み上げる必要のあるスライドがない
- [ ] どのスライドも、台本なしで読むと話が分からない。スライドだけで話が分かるなら載せすぎなので、説明を台本に戻す
- [ ] `../SKILL.md` の「スライド」の 6 項目を全スライドで満たす
- [ ] 本文の文字が最後列から読める大きさで、実際の表示サイズで確かめた
- [ ] デモがあるなら、失敗したときの録画か画面写真がある
- [ ] 反論 1 問を含む想定質問が 5 問以上ある
- [ ] 削れるセクションに印がある
- [ ] 声に出して 1 回通し、時間を測った。測れないときは台本の字数を 1 分 300 字で割って見積もり、見積もりだと明記した
