# 話の型と並べ方

## 話の型

既定は基本の型にする。下の表の「使う場面」に当てはまるときだけ他の型にする。

| 型       | 使う場面                       | 流れ                                         |
| -------- | ------------------------------ | -------------------------------------------- |
| 基本     | 大半の発表、進捗報告、教える場 | 挨拶 → 導入 → 本論 → 結論 → 質疑             |
| デモ     | プロダクトや仕組みを紹介する   | 価値 → 必要性 → 課題 → デモ → 広げたときの姿 |
| 問題解決 | 相手に変化を求める             | 課題 → 影響 → 解決策 → 次の行動              |
| 物語     | 感情を動かす、集中を保つ       | 状況 → 困難 → 道のり → 結果 → 教訓           |
| 消去法   | 意見が割れている               | 課題 → 選択肢 → 各案の限界 → 推奨            |
| 結論先行 | 役員への報告、判断を仰ぐ       | 結論 → 根拠 3 つまで → 各根拠の裏付け        |

### 基本の型の時間配分

| 部   | 中身                                                                             | 時間   |
| ---- | -------------------------------------------------------------------------------- | ------ |
| 挨拶 | 誰か、この話題を話す理由になる経験、聞く価値                                     | 約 5%  |
| 導入 | 話題 → 課題や背景 → 目的 → 持ち帰れるもの → 議題を 1 行 → 所要時間と質問の受け方 | 約 10% |
| 本論 | 3〜5 セクション。`section-map.md` の 4 要素をすべて持つ                          | 約 65% |
| 結論 | 終わりの合図 → 目的の再確認 → 要点のまとめ → 意味 → 次の行動                     | 約 10% |
| 質疑 | 感謝、質問を促す、答える                                                         | 約 10% |

導入は広い話から具体へ、結論は具体から広い話へ戻す。結論は要点の繰り返しで終えず、次の行動で終える。

### 型ごとの注意

- デモ: 機能一覧から入らない。聴衆が自分の課題を認めてから画面を見せる。最後は 10 倍の規模や他部署に広げたときの姿で締める。
- 問題解決: 影響を金額、時間、リスク、人数で数字にする。次の行動は担当者と期日のある具体的な一歩にし、「検討しましょう」で終えない。
- 物語: 主人公は 1 人、転機は 1 つ。教訓を聴衆自身の状況に結び付ける。
- 消去法: 自分が退ける案も公平に述べる。会場の誰かが推す案を弱く描かない。
- 結論先行: 最初のスライドで結論と頼みたい判断を言う。根拠は互いに重ならず、合わせると結論を支え切る 3 つまでにする。

## 本論の並べ方

1 つ選び、途中で混ぜない。

- 重要度順: 最重要から。役員や短い枠に使う。
- テーマ別: 同じ重さの話題を並べる。最初に「3 つ話します」と数を言う。
- 時系列: 経緯、ロードマップ、手順。各段に日付か段階番号を付ける。
- 原因と結果: 「何を」より先に「なぜ」を受け入れてもらう必要があるとき。
- 課題と解決: 各セクションが別々の課題とその答えを持つとき。

## つなぎ

セクションの境目では、次の 4 つを 1〜2 文で言う。即興にせず書いておく。

1. 今終えた内容の要約
2. それがなぜ大事だったか
3. 次に何を話すか
4. 2 つの関係

例:

- 「ここまでで、X が月に 40 時間を奪っていると分かりました。では、その 40 時間をどう取り戻すかを見ていきます。」
- 「ここまでが開発側の話です。同じ問題のもう半分が運用側で、次の 10 分はそちらを話します。」
- 終わりの合図: 「質問に移る前に、3 つの話をまとめます。」

複数人で話すときは、話し終える人が自分の部分を要約し、次の人を名前で紹介し、その人が何を話すかを言う。

## 物語の組み立て方

型の中の 1 セクションや導入・結論を書くときに、次から 1 つ選んで使う。

| 組み立て | 向く場面 | 流れ |
| --- | --- | --- |
| Golden Circle | 方針やビジョン、投資家への説明 | なぜ → どうやって → 何を |
| Minto Pyramid | 役員への説明、提言 | 結論 → 支える論点 → 裏付け |
| StoryBrand | 顧客向けの提案 | 顧客が主人公、自分たちは案内役、計画 → 成功と失敗の分かれ目 |
| Pixar Formula | 変革の説明、経緯 | 昔は → ある日 → そのため → ついに |
| South Park | 事例、プロジェクト報告 | 事実 → だから → しかし → だから |
| Challenger Sale | 複雑な提案営業 | 教える → 相手に合わせる → 主導する |
| In Medias Res | 導入、障害報告 | 山場から始め、あとで経緯を説明する |
