# 消してよいかの判定

- 消した版の 3 回がすべて、残した版と同じ結果なら消す。1 回でも悪くなったら残す。
- 比べるのは結果の行動（変更したファイル、実行したコマンド、返答の中の判断）。文面の一致では比べない。
- 依頼の文に候補の文の内容を書かない。
- 残した版でも期待する行動が出ない文は、守られていない文として扱う。lint・型・テストに移せるなら移し、移せないなら消す。
- 結果は違うが良し悪しを決められないときは、依頼を増やして 3 回ずつやり直す。それでも決められなければ残す。
- description を削るときは、その skill を呼ぶべき依頼と呼ぶべきでない依頼を 5 件ずつ作り、どちらの版でも起動の有無が同じであることを確かめる。
