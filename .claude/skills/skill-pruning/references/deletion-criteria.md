# 消す候補

## 候補にする文

- モデルが指示なしでも同じ行動を取る文。一般的なベストプラクティス、ツールやライブラリの基本的な使い方、公式ドキュメントに書いてあること。
- 同じ判断を別の言い回しで繰り返す文。skill の中、他の skill、AGENTS.md のどこか 1 か所に残し、他を候補にする。
- 前置き、要約、見出しを言い換えただけの文。
- 一度だけ起きた失敗を一般化した規則。まだ起きていない失敗に備える規則。
- 古いバージョンの API やモデルに合わせた指示。
- 「必ず」「絶対に」、大文字の MUST のように、強調だけで守らせようとする言い回し。強調を外した文を候補にする。
- 候補を選ぶために作ったどの依頼でも読まれない reference。

## 候補にしない文

- コードや設定を読んでも分からない、このリポジトリ固有の決定。
- モデルの既定と違う行動を求める文。
- 秘密情報、権限、取り返しのつかない操作に関わる文。検証で差が出なくても残す。
